# Why does the PBX Report hourly chart stop at 6:00 PM?

The hourly charts in **PBX Report** are generated according to the configured **working hours**.

By default, working hours are set from **9:00 AM to 6:00 PM**, so the hourly chart stops at 6:00 PM.

To change the displayed time range:

1. Log in to **PBX Report** with the `admin` user
2. Open **Settings** from the top-right corner
3. Change the configured **working hours**

The hourly charts will then use the new time range.

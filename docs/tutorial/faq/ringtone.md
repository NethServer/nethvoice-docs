# Can I use different ringtones for internal and external calls?

Yes. When inbound routes are created with **VisualPlan** and phones are provisioned by NethVoice, different ringtones are configured automatically:

* the **first ringtone** is used for internal calls
* the **second ringtone** is used for external calls

To change them:

* **Internal calls:** change the ringtone in the phone provisioning settings
* **External calls:** change the **Alert Info** field in the advanced settings of the inbound route

The phone must support the selected `Alert-Info` value.

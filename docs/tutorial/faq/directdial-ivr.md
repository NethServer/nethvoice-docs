# How do I configure an IVR to route digits directly to extensions?

When an IVR is created using **VisualPlan**, direct dialing to extensions is already enabled by default.

This means that callers can enter an extension number while the IVR is active and be routed directly to that extension, without any additional configuration.

The option that controls this behavior is available in the IVR advanced settings:

**Enable Direct Dial**

If the IVR was created with VisualPlan, this option is already enabled, so no further action is required.

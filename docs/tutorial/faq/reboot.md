# How to restart NethVoice and Asterisk

NethVoice and Asterisk can be restarted directly from the **NethServer administrative interface**.

Open the NethVoice application page, then go to the **Status** tab.

From this page, you can restart:

* **NethVoice**

Restarting the NethVoice application will also restart **Asterisk**.

Use the corresponding restart action for the service you need to restart.

This is the recommended way to restart these services without accessing the system from the command line.

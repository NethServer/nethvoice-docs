# Perché il grafico orario del PBX Report si ferma alle 18:00?

I grafici orari del **PBX Report** vengono generati in base all'**orario lavorativo** configurato.

Per impostazione predefinita, l'orario lavorativo è configurato dalle **9:00 alle 18:00**, per questo motivo il grafico orario si ferma alle 18:00.

Per modificare l'intervallo orario visualizzato:

1. Accedere al **PBX Report** con l'utente `admin`
2. Aprire le **Impostazioni** nell'angolo in alto a destra
3. Modificare l'**orario lavorativo** configurato

I grafici orari utilizzeranno quindi il nuovo intervallo configurato.

# Come configurare un IVR per instradare le cifre direttamente agli interni?

Quando un IVR viene creato utilizzando **VisualPlan**, la selezione diretta degli interni è già abilitata per impostazione predefinita.

Questo significa che i chiamanti possono digitare un numero di interno mentre l'IVR è attivo ed essere instradati direttamente verso quell'interno, senza alcuna configurazione aggiuntiva.

L'opzione che controlla questo comportamento è disponibile nelle impostazioni avanzate dell'IVR:

**Enable Direct Dial**

Se l'IVR è stato creato con VisualPlan, questa opzione è già abilitata e non è quindi necessaria alcuna ulteriore configurazione.

# Posso utilizzare suonerie diverse per le chiamate interne ed esterne?

Sì. Quando le rotte in ingresso vengono create con **VisualPlan** e i telefoni vengono provisionati da NethVoice, vengono configurate automaticamente suonerie differenti:

* la **prima suoneria** viene utilizzata per le chiamate interne
* la **seconda suoneria** viene utilizzata per le chiamate esterne

Per modificarle:

* **Chiamate interne:** modificare la suoneria nelle impostazioni di provisioning del telefono
* **Chiamate esterne:** modificare il campo **Alert Info** nelle impostazioni avanzate della rotta in ingresso

Il telefono deve supportare il valore `Alert-Info` selezionato.

# OpenAI

[OpenAI](https://openai.com/api) è una piattaforma di intelligenza artificiale che fornisce API per speech-to-text, text-to-speech e comprensione del linguaggio naturale.

**NethVoice** utilizza i servizi **OpenAI** per generare riepiloghi delle conversazioni e analisi del sentiment.

Dopo aver creato un account **OpenAI** e ottenuto una chiave API per accedere a questi servizi, la chiave deve essere configurata nella sezione **Integrazioni** del modulo **NethVoice** all'interno dell'interfaccia di **NethServer 8**.

Consulta [Configurazione del modulo NethVoice](../../administrator-manual/install/nethvoice_install#module-configuration).

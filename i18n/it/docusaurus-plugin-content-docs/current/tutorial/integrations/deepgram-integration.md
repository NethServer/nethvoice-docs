# Deepgram

[Deepgram](https://deepgram.com) è una piattaforma di elaborazione vocale basata sull'intelligenza artificiale che fornisce API per speech-to-text, text-to-speech e comprensione del linguaggio parlato in tempo reale.

**NethVoice** utilizza i servizi di Deepgram per generare trascrizioni in tempo reale delle conversazioni.

Dopo aver creato un account Deepgram e ottenuto una chiave API, configura la chiave nella sezione **Integrazioni** del modulo **NethVoice** all'interno dell'interfaccia di **NethServer 8**.

Consulta [Configurazione modulo NethVoice](../../administrator-manual/install/nethvoice_install#module-configuration).
